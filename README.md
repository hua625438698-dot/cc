# 时态小站

面向剑桥少儿英语（Starters / Movers / Flyers）的四大时态学习页：一般现在时、现在进行时、一般过去时、一般将来时（will 与 be going to）。含时间轴、讲解、时间词和练习，最后有综合练习与两篇短文填空。

本目录是**纯静态网页**，不引用任何外部字体、CDN、图片或统计代码，适合发布到国内静态托管。用手机或微信内置浏览器打开即可。

## 目录说明

- `index.html` 入口页面
- `style.css` 样式
- `app.js` 交互
- `data.js` 讲解与题库
- `favicon.svg` 图标

四个文件必须放在同一目录，不要改相对路径。

## 如何在国内发布

### 1）腾讯云 COS 静态网站

1. 登录 [腾讯云 COS](https://console.cloud.tencent.com/cos)，新建存储桶，地域选离你用户近的国内节点，访问权限选「公有读私有写」（仅网站文件，不要上传任何密钥）。
2. 在存储桶「基础配置 → 静态网站」中开启静态网站，将「索引文档」设为 `index.html`。
3. 把本目录全部文件上传到存储桶**根目录**（确保能访问到 `/index.html`、`/style.css`、`/app.js`、`/data.js`、`/favicon.svg`）。
4. 用静态网站提供的默认域名访问，例如 `https://<bucket>.cos-website.<region>.myqcloud.com`。
5. 如需绑定自己的域名：在 COS 里添加自定义域名，并到域名服务商处做 CNAME。**若域名要在中国大陆境内公网访问，必须完成 ICP 备案**，未备案域名无法在国内正常打开。

也可使用「对象存储 + CDN / EdgeOne」，同样需要备案后的域名。

### 2）阿里云 OSS 静态网站

1. 登录阿里云 OSS，创建 Bucket（国内地域），读写权限设为「公共读」（仅网站文件）。
2. 「基础设置 → 静态页面」开启，默认首页填 `index.html`。
3. 上传本目录全部文件到 Bucket 根目录。
4. 使用 OSS 静态网站域名访问；绑定自定义域名时，中国大陆同样需要 **ICP 备案**。

### 3）Gitee Pages

1. 在 Gitee 新建一个**公开**仓库，把本目录文件推送到仓库根目录（或 `docs` 目录，与 Pages 设置保持一致）。
2. 打开仓库「服务 → Gitee Pages」，启动 Pages，指定分支和目录。
3. 用 Gitee 分配的地址访问，例如 `https://<用户名>.gitee.io/<仓库名>/`。
4. 注意：Gitee Pages 对私有仓库或未实名账号可能有限制；访问高峰时免费 Pages 可能被限流。自定义域名在国内访问同样建议完成备案。

上传后请用手机和微信直接打开一次，确认讲解、练习、提交和成绩都能用（本站不依赖网络请求，但首次仍需把 HTML/CSS/JS 下载下来）。

## 重要说明：这是网页，还不是微信「小程序」

当前成品是 **H5 静态网页**，可以：

- 放到国内网站 / 对象存储上，把链接发给家长和学生；
- 在微信里直接打开这个链接（聊天、公众号菜单、二维码都可以）。

如果要做成能在微信里搜索、带底部导航的正式 **微信小程序**，需要另外用微信开发者工具做一次转换（例如用 web-view 包一层，或把页面改写成小程序 WXML/WXSS），并注册小程序账号、提交微信审核。本目录还不是可直接上传审核的小程序工程。如需改成小程序，可以再单独安排。

## 本地预览

用任意静态服务器打开即可，例如：

```bash
# 在本目录下
python3 -m http.server 8080
```

然后访问 `http://127.0.0.1:8080`。也可以直接用浏览器打开 `index.html`（部分手机系统对本地文件限制较严，正式使用请放到网站上）。
